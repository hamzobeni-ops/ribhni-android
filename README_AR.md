# ربحني – Ribhni (نسخة Android أولية)

هذه نسخة Flutter تجريبية لواجهة تطبيق مكافآت باللغة العربية:
- واجهة RTL وصفحات الرئيسية والمهام والمحفظة والسجل.
- نقاط تجريبية محلية داخل التطبيق.
- مكافأة دخول يومي تجريبية.
- اختيار بنكيلي كوسيلة دفع مستقبلية.

## تشغيل المشروع
1. ثبّت Flutter SDK و Android Studio.
2. فك ضغط الملف.
3. افتح مجلد `ribhni` في Android Studio أو VS Code.
4. نفّذ:
   ```bash
   flutter pub get
   flutter run
   ```
5. لبناء APK تجريبي:
   ```bash
   flutter build apk --release
   ```
   ستجد الملف عادةً في `build/app/outputs/flutter-apk/app-release.apk`.

## ما الذي لم يُفعّل بعد؟
هذه ليست نسخة إنتاجية ولا تحتوي على:
- تسجيل حسابات أو قاعدة بيانات سحابية.
- إعلانات حقيقية من AdMob.
- نظام منع الغش أو مراجعة المهام.
- دفع حقيقي إلى بنكيلي.

يجب قبل الإطلاق إعداد Firebase، وAdMob وسياسات الإعلانات، والتحقق من شروط Google Play، والحصول على توثيق/واجهة رسمية من بنكيلي أو مزود دفع مخوّل. لا تجمع أرقام بنكيلي أو بيانات مالية حساسة قبل وجود نظام آمن ومصرح به.

## لوحة الإدارة التجريبية
- افتح رمز الإدارة في أعلى الصفحة الرئيسية.
- بيانات الدخول التجريبية: `admin` / `demo12345`.
- تعرض لوحة الإدارة إحصاءات توضيحية وطلبات سحب وهمية مع أزرار موافقة/رفض تجريبية.
- هذه ليست حماية حقيقية: لا تنشر التطبيق بهذه البيانات. قبل الإطلاق يجب استخدام Firebase Authentication أو نظام مصادقة خادمي، مع صلاحية مدير محفوظة على الخادم وقواعد Firestore تمنع المستخدم العادي من تعديل الأرصدة أو اعتماد السحب.
